# Кряж — мототриал

Браузерный 2D-мототриал на TypeScript + Canvas 2D без внешних игровых библиотек:
собственная физика твёрдых тел, 12 авторских трасс в пяти биомах, процедурная
графика и синтезированный звук.

```bash
npm install
npm run dev      # разработка (сервер слушает и локальную сеть — можно открыть с телефона)
npm run build    # проверка типов + сборка в dist/
npm run single   # сборка одним файлом dist/kryazh.html
npm test         # авто-райдер проезжает все 12 трасс
```

## Управление

| Клавиша | Действие |
| --- | --- |
| ↑ / W | газ (в воздухе задирает нос — реакция заднего колеса) |
| ↓ / S | тормоз (в воздухе опускает нос) |
| ← / A, → / D | перенос веса назад / вперёд, вращение в полёте |
| ↓ + ← | задний ход на месте |
| Пробел / Shift | зажать — присед, отпустить — выпрыгивание |
| R / Enter | к чекпоинту |
| T / Backspace | трасса заново |
| Esc / P | пауза |

На сенсорных экранах появляются кнопки с мультитачем.

## Физика (`src/sim`)

Единицы — метры, килограммы, секунды; шаг интегрирования 1/480 с.

- **Четыре тела**: рама, два колеса с собственной массой и моментом инерции,
  райдер — отдельная масса на пружине. Перенос веса реально смещает центр масс.
- **Подвеска**: заднее колесо на маятнике (связь постоянной длины вокруг оси),
  переднее — на наклонной телескопической вилке. Пружина с преднатягом и
  прогрессией, раздельное демпфирование сжатия и отбоя, жёсткие ограничители.
- **Шины**: кулоново трение в пятне контакта с учётом вращения колеса. Тяга и
  тормоза — это момент на колесе с реакцией на раму, поэтому пробуксовка, юз,
  вилли, стоппи и управление тангажом в воздухе газом/тормозом получаются сами,
  а не заданы скриптом.
- **Поверхности**: трава, грунт, камень, дерево, металл, песок, грязь, снег, лёд —
  разные трение, сопротивление качению и вязкость.
- **Решатель**: последовательные импульсы (8 итераций на шаг) со стабилизацией
  Баумгарте; контакты — окружность против ориентированных сегментов.
- **Подвижные объекты**: качели с настоящим моментом инерции, паромы и
  подъёмники (кинематические), осыпающиеся доски.
- **Падение**: касание земли головой или корпусом; райдер превращается в
  тряпичную куклу (Верле), мотоцикл продолжает катиться сам.

Единственное намеренное упрощение — дополнительный момент «работы корпусом»
при наклоне (иначе сальто были бы почти невозможны) и усиленный толчок ног
при прыжке.

## Трассы (`src/levels`)

Трассы описываются цепочкой вызовов конструктора (`builder.ts`): холмы,
трамплины, пропасти, ступени, каменные россыпи, брёвна, валуны, своды, качели,
мосты, паромы, подъёмники. Каждая трасса вводит свою механику; на каждой три
звезды и три медали по времени. Рекордный заезд сохраняется призраком.

`npm test` запускает авто-райдера (`tools/bot.ts`): он проходит каждую трассу
от старта до финиша, перебирая скорость по участкам между чекпоинтами. Это
проверка проходимости, а не эталон времени.

## Графика и звук

Всё рисуется кодом: небо, солнце, звёзды и сияние, облака, четыре слоя
параллакса на биом (пики со снегом, столовые горы, ельники, вулканы), грунт с
пластами и текстурой, декор, мотоцикл с работающей подвеской и вращающимися
спицами, райдер на обратной кинематике, частицы, тени, погодные эффекты.
Звук двигателя, шин, ударов и сигналов синтезируется через Web Audio.
